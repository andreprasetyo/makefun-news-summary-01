# news-summary-01 — World news of Wednesday 11 November 2026

A one-paragraph summary of the day's world news, written in my own words
from reporting by Reuters, AP, AFP, BBC and NPR, for the make.fun
news-summary-01 competition. The program copies `summary.txt` to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (Node 22, standard library only, no network).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then check `out/entry.txt`: UTF-8, 1–2,000 characters, and byte-identical
across runs.
